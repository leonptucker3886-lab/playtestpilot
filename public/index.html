PlaytestPilot

Beta v0.2. Automated playtesting for indie web games.

A bot loads your game, presses keys at random, and watches for crashes, errors and frozen screens. Then it gives you a pass or fail report.

1. Quick test in your browser

Paste a game URL and press Run. With no setup this only checks that the page loads and can be embedded. For key presses and error capture, add one line to your game first:
<script src="https://playtestpilot.vercel.app/ptp-sdk.js"></script>

Waiting…

2. Full test with the bot (GitHub Action)

The full bot runs headless Chrome with real keyboard input. In the repo, open Actions → PlaytestPilot → Run workflow, enter your game URL, and read the pass or fail in the run summary. The JSON report and final screenshot are attached to the run. Each run prints a seed, so you can repeat a failing run exactly.
